# ⚔️ 宝可梦对战（Pokémon Battle）

一个运行在浏览器里的**完整宝可梦对战模拟器**，基于 [Pokémon Showdown](https://pokemonshowdown.com/) 官方对战引擎（`@pkmn/sim`）构建。覆盖 **9 个世代全部宝可梦、招式、特性、道具**，支持单打 / 双打，以及 **超级进化、Z 招式、极巨化 / 超极巨化、太晶化** 全部特殊对战机制，并内置多分类中文图鉴。

无需服务器、无需注册，打开网页即可与 AI 对战。

---

## ✨ 功能一览

### 🎮 对战
- **11 种对战规则**：随机单打 / 双打、自定义单打 / 双打、OU 标准规则、VGC 6 选 4 双打，以及专门的机制展示规则（第七世代超级进化 / Z 招式、第八世代极巨化）
- **全部特殊机制**，玩家可主动使用，AI 也会智能使用：
  - 🧬 **超级进化**（Mega Evolution，第七世代）
  - 💎 **Z 招式**（Z-Moves，第七世代，含通用属性 Z 与专属 Z）
  - ⬆️ **极巨化 / 🔥 超极巨化**（Dynamax / Gigantamax，第八世代）
  - ✨ **太晶化**（Terastallize，第九世代）
- 完整对战系统：属性克制、STAB、能力等级变化、异常状态、天气 / 场地、入场 hazards（隐形岩 / 撒菱 / 毒菱）、反射壁 / 光墙、换人、队伍预览、双打目标选择
- 智能 AI：按期望伤害评分选招、按抗性换人、合理释放极巨化 / 超级进化 / Z 招式 / 太晶化
- 中文对战日志、受击 / 攻击动画、机制徽章与极巨化视觉特效

### 🧩 组队
- 从 **全部 9 世代 1000+ 宝可梦（含形态）** 中自由组队（最多 6 只）
- 完整配置：技能（按真实学习面过滤）、特性（含隐藏特性）、道具、性格、等级、努力值（EV，510 上限自动钳制）、个体值（IV）、太晶属性、闪光、超极巨化因子
- **一键预设队**：示例 OU 队、超级进化 / Z 队（gen7）、极巨化队（gen8，含 4 只超极巨化宝可梦）、随机队伍
- 支持 **Showdown 文本格式导入 / 导出**，队伍自动保存在浏览器本地（localStorage）
- 开始对战前自动进行规则校验，不符合规则会给出具体原因

### 📖 图鉴（六大分类）
| 分类 | 内容 |
| --- | --- |
| 🐾 宝可梦 | 全世代物种：官方绘图、种族值、特性、防御克制、完整可学技能表 |
| ⚔️ 招式 | 685 个常规招式：属性 / 分类 / 威力 / 命中 / PP / 优先度 / 目标 / 效果说明，可按属性筛选 |
| 🎒 道具 | 500+ 携带道具：超级石、Z 纯晶、树果、攻击 / 防御 / 功能道具等分类筛选；超级石展示进化前后对比 |
| 🧠 特性 | 310 个特性：完整效果说明与登场世代 |

## 🚀 快速开始

### 环境要求
- [Node.js](https://nodejs.org/) ≥ 18（推荐 20+）
- npm（随 Node.js 安装）

### 本地运行

```bash
# 1. 克隆仓库
git clone https://github.com/<你的用户名>/pokemon-battle.git
cd pokemon-battle

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

打开浏览器访问终端提示的地址（默认 `http://localhost:5173`）即可开始游戏。

### 构建发布版

```bash
npm run build     # 类型检查 + 打包，产物在 dist/
npm run preview   # 本地预览打包产物
```

`dist/` 是纯静态文件，可直接部署到 **GitHub Pages / Vercel / Netlify** 等任意静态托管。

> 💡 部署到 GitHub Pages 时，若仓库不是根域名（如 `username.github.io/repo`），请在 `vite.config.ts` 中设置 `base: '/仓库名/'` 后再构建。

## 📖 使用指南

### 1️⃣ 最快上手：随机对战
1. 打开网页，默认在「⚔️ 对战」页
2. 选择 **随机单打**（含太晶化）等随机规则，点击「开始对战」
3. 双方队伍由系统随机生成，直接开打

### 2️⃣ 使用自己的队伍
1. 到「🧩 组队」页，点击「＋ 添加宝可梦」搜索并配置，或直接点预设按钮一键加载：
   - 📋 **示例 OU 队** —— 第九世代标准阵容
   - 🧬 **超级进化/Z队** —— 喷火龙 X / 胡地 / 烈咬陆鲨超级石 + 皮卡丘 / 卡比兽 / 卡璞・鸣鸣 Z 纯晶
   - 🔥 **极巨化队** —— 喷火龙 / 耿鬼 / 拉普拉斯 / 闪焰王牌（均可超极巨化）
2. 到「⚔️ 对战」页选择自定义 / OU / VGC 规则（页面会显示该规则支持的特殊机制标签）
3. 队伍校验通过后点击「开始对战」；有队伍预览的规则需先点选出场顺序

### 3️⃣ 特殊机制怎么用

对战行动面板中，当前宝可梦可用机制会显示为按钮（每回合每只宝可梦只能选一种）：

| 按钮 | 操作 | 规则 |
| --- | --- | --- |
| 🧬 超级进化 | 点亮后点击任意招式，出招同时超级进化 | 需携带对应超级石；每场对战一次 |
| 💎 Z 招式 | 点亮后招式按钮变为金色 Z 招式，点击释放 | 需携带 Z 纯晶；每场一次；必定命中、可击穿守住 |
| ⬆️ 极巨化 / 🔥 超极巨化 | 点亮后招式按钮变为红色极巨招式，点击释放 | 第八世代规则；持续 3 回合；HP 翻倍；**双打中每回合全队只能一只极巨化** |
| ✨ 太晶化 | 点亮后点击任意招式，出招同时太晶化 | 第九世代规则；每场一次；属性变为太晶属性 |

> ⚠️ 机制是否可用取决于**规则世代 + 队伍配置**：
> - 超级进化 / Z 招式 → 选「超级进化/Z·单打」或「随机·超级进化/Z」，并让宝可梦携带超级石 / Z 纯晶
> - 专属 Z 纯晶需要特定基础招式（如卡比兽的「卡比兽 Z」需要**终极冲击**）
> - 极巨化 → 选「极巨化·单打 / 双打」或「随机·极巨化」；超极巨化需要该宝可梦具备超极巨化因子（预设「极巨化队」已配好）
> - 太晶化 → 第九世代规则均可用

### 4️⃣ 图鉴与克制表
- 「📖 图鉴」页顶部切换六大分类，左侧搜索（支持中文名 / 英文名 / 图鉴编号）+ 筛选，右侧查看详情
- 「🎯 属性克制」页查看完整克制表，或用防御计算器查询任意双属性组合的弱点

## ❓ 常见问题

**Q：图片不显示？**
A：精灵图与官方绘图来自 `play.pokemonshowdown.com` 与 GitHub（PokeAPI），需要联网。首次加载对战数据（约 10 MB）也需几秒钟，请耐心等待加载页结束。

**Q：为什么看不到超级进化 / 极巨化按钮？**
A：机制与规则世代绑定。请在支持该机制的规则下对战，并确保宝可梦携带了对应道具（超级石 / Z 纯晶）。最简单的方式是直接加载对应预设队并选择对应规则。

**Q：队伍会丢失吗？**
A：队伍保存在浏览器 localStorage 中，同一浏览器下次打开仍在；换浏览器 / 清除缓存会丢失，可用「导出」备份为 Showdown 文本。

**Q：可以和真人对战吗？**
A：当前版本为单机 vs AI。引擎本身支持双玩家协议，欢迎提 PR 扩展联机功能。
